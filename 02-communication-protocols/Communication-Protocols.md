# Communication Protocols

Protocols are agreed rules for exchanging data.

- HTTP/HTTPS: web APIs
- TCP: reliable, ordered byte stream
- UDP: low-overhead datagrams without delivery guarantees
- WebSocket: long-lived, two-way browser communication
- gRPC: efficient service-to-service RPC
- DNS: converts domain names to IP addresses
- FIX: commonly used for financial trading communication

Choose a protocol based on reliability, latency, streaming needs, client support, and operational complexity.
