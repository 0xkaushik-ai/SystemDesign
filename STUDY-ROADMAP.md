# System Design Study Roadmap — 20 LPA Target

Study in this order:

1. HTTP and communication protocols
2. OSI model, packets, frames, and Ethernet
3. TLS and secure communication
4. gRPC and service-to-service communication
5. Distributed systems
6. Message brokers
7. Caching and multicasting
8. Trading-platform case study
9. Databases and SQL
10. Load balancing, API design, and rate limiting
11. Consistency, reliability, and observability
12. Low-level design, DSA, operating systems, and interviews
13. System-design case studies

For every topic, learn the definition, draw the architecture, understand the trade-offs, and explain one real-world example aloud.

## Interview habit

For each design, clarify requirements, estimate scale, define APIs and data, draw a high-level design, then discuss bottlenecks, failures, consistency, security, and monitoring.
