# HTTP

HTTP is an application-layer request/response protocol used by clients and servers.

```text
Client ── HTTP request ──> Server
Client <─ HTTP response ─── Server
```

Learn methods (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`), status codes, headers, body, cookies, authentication, HTTPS, caching, REST, HTTP/1.1, HTTP/2, and HTTP/3.

Important interview ideas: latency, connection reuse, timeouts, retries, rate limiting, load balancers, and idempotency.
